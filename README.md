# 星际守卫

一个无需安装依赖的打飞机小游戏。手机上拖动战机移动，电脑上可用方向键或 WASD；战机会自动射击。敌机撞到战机或飞出屏幕会损失生命。最高分保存在当前浏览器中。

## 本地运行

在仓库目录运行：

```sh
python3 -m http.server 8000
```

然后在浏览器打开 `http://localhost:8000`。也可直接打开 `index.html`。

## Boss 与武器升级

每局开始 15 秒后出现 360 血量的 Boss，发射扇形弹幕，半血后加快攻击。击败获得 500 分并恢复一条生命（最多三条），之后继续挑战普通敌机。

所有武器自动发射、同时生效，按击杀数升级（最高三级）：
- 普通子弹：初始一级，5 / 10 击杀升到二 / 三级，增加弹道、伤害和射速。
- 激光：6 击杀解锁，12 / 18 击杀升级，纵向穿透并提高伤害和频率。
- 追踪导弹：8 击杀解锁，16 / 24 击杀升级，自动锁定最近敌人，目标消失后重新锁定；增加数量、伤害和频率。

重新开始会重置 Boss、武器和升级进度。
